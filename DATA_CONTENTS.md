# Data-content review

Scope: the local `cvd_ipf_pah_final` predictor project and the two curated container handoff archives. This is not an audit of unrelated files on the computer, the entire original Downloads directory, or remote server logs.

## Findings

- No raw UKBB/BBRU participant table, clinical record, participant identifier array, uploaded patient workbook, or patient-level outcome dataset was found in the inspected predictor artifacts.
- Serialized model inspection found sklearn random forests/decision trees, a BBRU imputer/scaler/logistic adapter and calibrator, class labels, feature names, coefficients, thresholds, leaf statistics, and aggregate training/performance metadata. It did not reveal stored training feature matrices or subject identifiers.
- `feature_medians.tsv` contains one aggregate median per feature, not one row per participant.
- `deployment.json` contains fitted adapter/calibration parameters and aggregate BBRU counts/metrics.
- The compact CVD arrays contain tree child indexes, split feature indexes, thresholds and leaf positive-class values. They do not contain participant IDs or a training table.
- Original example CSVs use `SYNTHETIC-*` identifiers and training medians. Reference test inputs were generated using seeded random values/medians in the export scripts. Examples and reference tests are excluded from these handoff archives.

## Handoff contents

The source archive contains only runtime source, HTML/CSS/JavaScript, dependencies, Docker/Compose/Caddy configuration, setup and checksum scripts, and this documentation. The model archive contains 64 required model/metadata files. It omits the redundant original CVD forest and legacy BBRU joblib adapter; their compact/numeric runtime equivalents are used instead.

No live password, password hash, session secret, cPanel configuration, browser cookies, local environment, IDE files, logs, or user-uploaded workbook is included. Credentials must be generated by the recipient.

## Limits

Absence of raw participant records does not establish formal anonymization or zero disclosure risk. Fitted trees contain training-derived thresholds and leaf statistics; other artifacts contain aggregate summaries. Model membership/reconstruction risks were not tested. This review does not determine whether a particular transfer is permitted under UKBB/BBRU project arrangements. Share trained assets only with an authorized recipient through private transfer.
